# 数据获取、检查和发布

1. 读取：使用保存的字段映射选取企业微信子表，按游标分页；快速预览最多 200 行，不能发布。
2. 完整性检查：核对总行数、字段、记录 ID、重复游标，再完整读取第二遍比对内容哈希。源表变化则停止。
3. 数据检查：转换日期、时间、类型、人员及校历多行事件。空白源行先排除，避免默认类型制造假记录。预览和云端发布共用 `shared/data-validation.cjs`，错误显示数据条号；空结果、超容量、超大小的数据不可发布。
4. 发布：核对登录会话、映射指纹、目标环境和写入开关；备份旧数据，使用 ETag 条件覆盖。三个模块分别发布，不是跨模块事务。
5. 结果：自动 dev 同步读取目标并比对哈希；写入响应未知时只读核对，禁止盲目重发。服务明确拒绝写入时允许修正后重试。中断后未执行的模块显示未完成。手动发布成功后，历史列表加载失败不会再显示成发布失败。
