# 本地一键同步 dev

本地工作台新增“同步到 dev”。不是定时同步；只有登录本地工作台的用户点击按钮才启动，不推送代码、不合并分支、不访问 main。

## 首次配置

1. 为三个模块分别读取子表、字段，确认后保存映射。一键同步使用磁盘上已保存的映射，而非当前尚未保存的草稿。
2. 展开“dev 同步设置”：目标固定为已批准的 dev 分支地址。本机 HTTP 代理预填 `http://127.0.0.1:7897`，不使用代理可清空。
3. 用户自行填写 Preview 管理员密码和 Vercel 自动化访问 Secret，勾选允许保存。Secret 由用户在 Vercel 创建，本功能不会创建凭据、关闭部署保护或保存 Vercel 登录 Cookie。
4. 配置存于被 Git 和 Vercel 排除的 `data/dev-sync-config.json`，原子保存，文件权限 600。**文件未加密**，本机当前账号仍可读取；不要共享账号或把文件放入公共备份。接口不回显密码和 Secret。留空保留，勾选清除可移除。
5. 点击“验证连接（不发布）”，成功后再选择模块并点击“一键同步到 dev”。

## 同步与故障

- 登录验证后逐模块执行全量分页、双遍核对、解析与发布前校验。原有云端备份、条件写入和环境检查继续生效。
- 发布后读取目标数据，内容摘要一致才标记成功；接口仅返回成功不算最终验收。
- 发布之前将不确定状态写入本机日志。断网、响应丢失或服务重启后不自动重发；有不确定模块时禁止再次一键同步和手动 dev 发布/回退。
- “核对上次发布结果”仅执行读取；不一致或无法读取仍保持待核对，需人工检查，不以按钮强行清除。
- 读取失败的模块不发布，可以继续其他模块。发布结果不明时停止余下模块，显示“未执行”。不提供跨模块事务承诺。
- 刷新页面可以恢复进度；服务重启不自动继续源表读取。凭据配置会保留。

本次实现使用模拟数据覆盖状态管理与安全边界；没有填入真实发布凭据，没有执行真实一键同步或生产发布。实际连接及真实数据同步待用户填写凭据后验收。
